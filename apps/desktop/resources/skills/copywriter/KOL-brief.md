# KOL Brief

This skill produces the brief that goes to the influencer / creator — NOT the audience-facing content. A KOL brief is fundamentally different from a regular creative brief because:

- The creator's voice must dominate, not the brand's
- Over-specifying kills authenticity (and the algorithm penalizes inauthentic content)
- Compliance disclosures (FTC #ad / AI-tool use) are legally required in 2026
- Each KOL has a personal brand that the campaign must respect

## When to Use

Fire when the brief mentions:
- KOL / KOC / influencer / creator / 达人 / 博主 / up 主
- partnership / 合作 / 推广
- Number of creators ("5 KOLs" / "招 30 个达人")
- Content brief for external creators (vs in-house team)

Skip when: brief is for in-house content; brief is for ad copy (route to Ad Copywriting); brief is for the audience (route to Editorial Content / Ad Copywriting).

## Apply

### 1. KOL Identification & Persona Match

For each KOL in scope, document or align on:

- Creator name + handle
- Platform(s): where they post
- Audience profile: demographic + psychographic (pulled from Audience Persona via Market Discovery if available)
- Personal brand voice: how they normally sound (use 2-3 example posts as reference)
- Content niche: lifestyle / beauty / tech / B2B / etc.
- Authenticity signals they preserve: what makes their content theirs (not generic ad voice)

Match logic: each KOL is hired for a SPECIFIC angle. A brief that asks 5 different KOLs to say the same thing in the same way is a wasted spend. Each KOL brief should pull a different angle from the Big Idea.

### 2. Campaign Overview (per brief)


**Campaign name**: [internal name]
**Brand**: [name + 1-line description for creator context]
**Big Idea / Creative Platform**: [the chosen Big Idea route]
**This KOL's angle**: [the specific angle this creator is hired for]
**Campaign goal + KPI**: [what success looks like]
**Audience the creator is reaching**: [their audience, not the brand's general target]


### 3. Deliverables (platform-specific)

For each piece of content the KOL produces:

| Field | Detail |
|---|---|
| Platform | IG / TikTok / XHS / YouTube / etc. |
| Format | Reel / Carousel / Story / Note / Short / Long-form |
| Spec | Pull from Platform Image Style / Platform Video Style |
| Quantity | How many posts |
| Length / Slide count | Per format conventions |
| Trending audio | Required / recommended / optional |
| Caption length | Per platform conventions |
| Hashtag count | Per platform (IG ≤5-10, LinkedIn ≤5, XHS ≤5, FB 0-2) |

### 4. Must-Mentions

- Brand handle to tag: @brand
- Campaign hashtag: #[specific]
- Required disclosure hashtag: #ad / #sponsored / #partnership (FTC requirement in 2026)
- Suggested hashtags (optional): 3-5 discoverability hashtags
- Product name: exact spelling / formatting
- Key claims (with compliance check): what they CAN say about the product

Do NOT require 20+ mandatory hashtags — cluttered captions tank both creator authenticity and algorithm performance.

### 5. Avoid Items

- Hashtags to avoid: competitor names, off-brand tags, deprecated campaigns
- Phrases to avoid: claims the brand can't legally make (route through compliance sub-agent if uncertain)
- Visual elements to avoid: competitor products in frame, off-brand color use, prohibited contexts
- Tone to avoid: anything inauthentic to the creator's voice

### 6. Do's and Don'ts

Do:
- Speak directly to camera (for video)
- Keep content native and creator-led
- Show genuine product use / try-on / before-after where applicable
- Use creator's own examples and stories
- Lead with the angle, then layer brand mention

Don't:
- Read brand copy verbatim (kills authenticity)
- Use heavy beauty filters that hide the product result
- Open with brand logo (algorithm de-boost)
- Make claims not in the must-mention list
- Use phrases / formats inauthentic to the creator's brand

### 7. Content Direction (suggestions, not mandates)

Provide 2-3 content angle suggestions the creator can choose from — not a script:

- Angle 1: [scenario / hook idea]
- Angle 2: [different scenario]
- Angle 3: [different scenario]

Note: "Final execution is yours — these are starting points, not scripts. Pick one or combine."

### 8. Timeline

- Brief delivered: [date]
- Draft submission deadline: [date, typically 1-2 weeks from brief]
- Brand review window: [date — typically 2-3 business days]
- Revision turnaround if needed: [date]
- Final approval: [date]
- Live posting window: [date range — use range, not single date, for creator scheduling flexibility]

### 9. Compliance & Disclosures (2026 Requirements)

FTC / Regional Disclosure:
- US: #ad or #sponsored visible (NOT hidden in hashtag list); use platform native paid partnership label
- UK: #ad clearly visible
- HK / CN: appropriate market disclosure per local law
- Platform native paid partnership label MANDATORY on IG / TikTok / YouTube

AI Disclosure (NEW for 2026):
- FTC now requires disclosure if creator uses AI tools in content generation
- Include in brief: "If you use AI tools (image generation, voice clone, etc.), disclose per FTC 2026 guidelines"

Compliance hand-off: if product is medical / health / financial / weight-loss → route brief through compliance sub-agent before sending to creator

### 10. Usage Rights

Specify clearly (this is where partnerships go wrong):
- Repost rights: can brand repost the creator's content to brand channels? Y/N
- Duration: 3 months / 6 months / 12 months / perpetual
- Paid ad rights: can the content be boosted as paid ad? Y/N (separate budget often)
- Whitelisting: can the brand run paid ads under the creator's handle? Y/N (premium add-on)
- Geographic restrictions: any market limits

### 11. Compensation (if in scope)

- Flat fee / per-post / performance-based (CPC / CPM / CPA)
- Payment terms
- Product gifting (specify what + value)
- Exclusivity period (if any)

## Defaults

- No KOL list provided → surface that KOL identification is upstream; route through Market Discovery (Audience Persona for KOL profiles) first
- No angle differentiation per KOL → propose 3 distinct angles (one per KOL) based on the chosen Big Idea
- No usage rights specified → default to repost rights for 6 months, no paid boost (conservative); flag for user to expand
- No compensation defined → leave compensation section empty with note that this is partnership-team decision
- No content direction angles specified → derive 2-3 from Big Idea's Creative Platform; surface

## Hard Limits

- Never write a single brief for multiple KOLs — each gets their own; copy-paste briefs produce copy-paste content that the algorithm and audience reject
- Never script the creator — provide angles and must-mentions, not exact wording (defeats the purpose of hiring a creator)
- Disclosure section MANDATORY — FTC 2026 compliance is non-negotiable
- AI-tool disclosure required if any AI tool used in production (FTC 2026)
- Compliance-sensitive products (medical / health / financial / weight-loss) → route through compliance sub-agent before brief is sent
- Never require 20+ hashtags — cluttered captions hurt both creator and algorithm
- Never force trending audio if it conflicts with creator's normal content style — inauthenticity kills performance
