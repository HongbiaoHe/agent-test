# Ad Copywriting

This skill handles paid ad copy and landing page copy — the conversion-focused copy that has to work in seconds and pay back its CPM. It is NOT for organic captions or video scripts (route those to Editorial Content).

Two scenario branches:
- Dark Post Ad Copy — paid social ads (IG / FB / TikTok / LinkedIn dark posts, boosted posts, sponsored content)
- Landing Page Conversion — LP / sales page / product page conversion copy

All output passes the 4U quality test before delivery.

## When to Use

Fire when:
- Brief specifies paid ad / dark post / boosted post / sponsored content / Meta ad / TikTok ad / LinkedIn ad
- Brief asks for landing page / sales page / product page copy
- Brief asks for headline / hook / CTA standalone (route through 4U quality test)

Route to Editorial Content instead when: organic IG / Threads / XHS caption, short-video script (15s / 30s / 60s).

## Scenario A — Dark Post Ad Copy

### A.1. Problem (Hook — 0-2 seconds)

- Identify the "bleeding neck" — pain so specific the reader stops cold
- Cold audience: universal urban frustration, no brand mention
- Warm / Hot audience: reference what they already know about you
- Character limits:
  - IG / FB: ≤125 chars before "... more" truncation
  - TikTok: ≤100 chars caption
  - LinkedIn: ≤150 chars first line

### A.2. Agitate (40-50% of total copy)

- Amplify cost of inaction
- Name failed alternatives they've tried ("You tried [X], [Y], even [Z], nothing worked")
- Do NOT introduce the product here — stay with the pain

### A.3. Solution

- One sentence: what it is + how it works (mechanism)
- Immediately follow with strongest proof point (data / authority / case study)
- Then CTA — urgency only if genuine (real deadline, real scarcity)

### A.4. CTA — Social Safety Test

- Makes user feel smart / high-status → use it
- Requires admitting a problem publicly → rewrite (kills click-through)
- Formats: Comment [KEYWORD] / DM me [WORD] / Tap to see how / Save this and read tonight

### A.5. Output for Dark Post


**Platform**: [IG / FB / TikTok / LinkedIn]
**Audience temperature**: [cold / warm / hot]
**[PROBLEM]**: [hook, ≤platform char limit]
**[AGITATE]**: [40-50% of total]
**[SOLUTION]**: [one sentence + proof point]
**[CTA]**: [exact line]
**Character count** per section
**Text-on-asset headline**: [≤8 words for the visual overlay]


## Scenario B — Landing Page Conversion

### B.1. Hero Section

- Headline (H1): outcome-focused, not feature-focused; 6-10 words ideal
- Subhead: clarifies who it's for + what's different; 1-2 lines
- Hero CTA: action verb + value ("Get the cream" beats "Buy now")
- Trust signal above the fold: review count / press logo / customer count

### B.2. Feature → Benefit Translation

Every feature must be translated into a benefit. The product page mistake is listing features ("24-hour battery, IPX5 waterproof") instead of benefits ("Survives a full workday without a charger; sweat-proof for gym sessions").

Structure:
- Feature: [technical spec]
- Advantage: [what that enables]
- Benefit: [what user gets / feels]

Use FAB structure for spec-heavy products; use Problem-Solution for emotional / lifestyle products.

### B.3. Trust Signal Hierarchy

In order of impact (use top-down based on what's available):

1. Customer count + recency ("50,000 served in 2026" beats vague "thousands")
2. Press / authority logos (named publications > random badges)
3. Specific results with numbers ("reduced X by 38% in 30 days")
4. Testimonials with full name + photo (anonymous quotes look fake)
5. Founder credentials (only if credentials match product authority)
6. Money-back guarantee (clarifies risk, lifts conversion 5-15%)

### B.4. Page CTA Strategy

- Above fold: primary CTA (e.g., "Add to cart")
- Mid-page: repeated primary CTA after benefit section
- End of page: primary CTA + secondary (e.g., "Not sure? See reviews")
- All CTA verbs: action + value ("Start the trial" not "Submit")

### B.5. Output for Landing Page


**Page type**: [product / sales / squeeze / VSL]
**Hero headline**: [6-10 words]
**Hero subhead**: [1-2 lines]
**Above-fold CTA**: [verb + value]
**Trust signals** (in order): [list]
**Feature → Benefit blocks**: [3-5 of them]
**Social proof section**: [testimonial selection + format]
**Mid-page CTA**: [exact line]
**Objection handling section**: [3-5 objections + responses]
**End CTA**: [primary + secondary]


## Common Quality Standard — 4U Headline Test

Every hook, headline, subhead, and CTA must pass the 4U test before output:

- Urgent: time-relevant; "now" / "this year" / specific timing OR clear reason to act today
- Unique: not interchangeable with a competitor's line; if your direct competitor could say the exact same thing, fail
- Ultra-Specific: numbers / outcomes / details over abstractions ("5 Steps" not "A Few Steps"; "28-Day Result" not "Amazing Results")
- Useful: clear value to viewer in 0.3 seconds of reading

Scoring:
- 4/4 = ship
- 3/4 = ship if the missing U is Urgent (urgency can come from context)
- 2/4 = rewrite
- 1/4 = scrap

If the brief explicitly wants soft / aspirational tone (Premium Trust brands often do), the Urgency dimension can be softened — but Specificity and Uniqueness are non-negotiable.

## Output Format

Return copy with:
- Scenario (Dark Post / Landing Page)
- Platform / placement (for Dark Post)
- Structured sections per scenario above
- 4U score for each headline / hook / CTA
- Character counts for any platform-limited section

## Defaults

- No platform specified for Dark Post → ask before defaulting; do NOT silently choose IG
- No audience temperature → default to cold (defensive); ask user to confirm
- No primary CTA defined → derive from page goal (purchase / lead / trial); surface choice
- No trust signals available → flag; recommend collecting before launch (lifts conversion 20-40%)
- No proof point available for Solution → flag; ask user for one (proof-less Solutions tank conversion)

## Hard Limits

- Never use manufactured scarcity ("only 3 left!" when not true) — Meta / Google reject these ads
- Medical / health claims → flag for compliance sub-agent; do NOT auto-write
- Financial guarantees → flag for compliance sub-agent
- Weight loss / before-after → flag for compliance sub-agent
- CTA never "public confession" format — anything that requires user to admit a problem to their followers kills CTR
- Hero headline never feature-led (list of specs) — always outcome-led
- Trust signals never fake — made-up review counts, anonymous testimonials, fake awards
- zh-HK market: Traditional Chinese; zh-CN market: Simplified
