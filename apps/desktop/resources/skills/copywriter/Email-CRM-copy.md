# Email / CRM Copy

This skill writes the full email — not just the body, but the four critical pieces that determine whether the email gets opened, read, and clicked:

1. Subject line (determines open)
2. Preview text (the second hook, shown in inbox preview)
3. Hero / body copy (determines read-through)
4. CTA (determines click)

In 2026, average open rate sits 21-31% across sectors (and is inflated 10-15% by Apple Mail Privacy Protection). The real KPIs are click-through and conversion — which is why this skill optimizes the full chain, not just the open.

## When to Use

Fire when brief calls for:
- Promotional / sale email
- Newsletter
- Welcome / onboarding sequence
- Abandoned-cart / browse abandonment
- Re-engagement / win-back
- Event invite / RSVP
- Launch announcement email
- Sales sequence (cold or warm)

Route elsewhere when: organic social caption (Editorial Content); paid ad copy (Ad Copywriting); LP copy (Ad Copywriting).

## Apply

### 1. Subject Line

Character limit: ≤50 chars (Gmail / Outlook truncation); 35-45 chars is ideal for mobile.

Length finding: subject lines under 4 words have a 45% higher open rate — short beats long.

Emoji rule: in B2C, emojis lift open rate +56%; in B2B, emojis drop open rate -4%. Use accordingly:
- B2C / consumer brand → strategic emoji at start or end (not both)
- B2B / LinkedIn-style audience → no emoji

Subject line patterns (pick by goal):

| Pattern | When to use | Example |
|---|---|---|
| Curiosity gap | TOF awareness / newsletter | "What I learned from $0 → $1M" |
| Specific outcome | DR / product launch | "Save 32 mins on every commute" |
| Personal name | Welcome / re-engagement | "Sarah, your skincare match is here" |
| Question | Engagement / re-engagement | "Still thinking it over?" |
| News / announcement | Launch / event | "We just dropped the [X]" |
| Urgency (real) | Sale / event RSVP | "Last 6 hours" |
| Pattern interrupt | Re-engagement | "This isn't a sales email" |

Subject line never patterns:
- All caps ("AMAZING OFFER") — spam filter triggers
- Multiple exclamation marks ("!!!") — spam triggers + reads desperate
- "Re:" or "Fwd:" when not actually a reply — erodes trust on discovery
- Manufactured urgency ("Last chance!" when not true) — erodes long-term trust
- Generic ("Our weekly newsletter") — 0% curiosity

### 2. Preview Text

Preview text is the second hook, shown in the inbox preview right after the subject line. It must:
- Complement the subject (not repeat it)
- Add a second reason to open
- Stay ≤90 chars (mobile inbox preview truncation)

Wrong: Subject = "Sale starts now" / Preview = "Don't miss our sale" (repeats)
Right: Subject = "Sale starts now" / Preview = "Plus a gift for the first 200 orders" (adds layer)

### 3. Hero Header (inside the email)

- Length: 4-8 words; bigger type, scannable in 0.5 seconds
- Function: confirms the subject line's promise; orients the reader
- Tone: aligned with subject line's tone (don't open curiosity-gap and immediately become salesperson)

### 4. Body Copy

Mobile-first composition:
- Short paragraphs (1-3 sentences each)
- Line breaks between sections
- Bold key value moments
- Bullets / lists when listing benefits
- Total body: 50-150 words for promotional; 150-300 for newsletter / educational

Structure (depends on email type):

Promotional:

Hero header (4-8 words)
Problem / context (1-2 sentences)
Product / offer (1-2 sentences)
Key benefit + proof (1-2 sentences)
Primary CTA button
[Optional secondary line: "Not for you? [reason to stay subscribed]"]


Newsletter:

Hero header (4-8 words — the issue topic)
Lead paragraph (3-4 sentences — the insight)
Supporting paragraph (3-4 sentences — the example / data)
Takeaway (1-2 sentences — the so-what)
Primary CTA (read full article / book session / save resource)


Welcome / Onboarding:

Hero header (Welcome / first-name)
What to expect (3 bullets — the next 7 days)
First-action CTA (the one most important step)
Social proof line (1 sentence)


Abandoned Cart:

Hero header ("You left this behind")
Product image + name
Key benefit (1 sentence — why this matters)
Gentle nudge (1 sentence — stock / time-limited if true; never manufactured)
Primary CTA (Complete purchase)
[Secondary: "Save for later"]


Re-engagement:

Hero header (acknowledgment of absence)
What's new since they were last engaged (2-3 bullets)
Clear binary CTA (Stay subscribed / Update preferences)


### 5. CTA

Rule: ONE primary CTA per email.

Single-CTA emails generate 371% more clicks than multi-CTA emails. Multiple CTAs split attention; reader picks none.

CTA copy:
- Specific over generic ("See the spring collection" beats "Click here")
- Outcome over action ("Claim your 20% off" beats "Buy now")
- 2-5 words; tap-friendly button (44×44px minimum on mobile)

CTA placement:
- Always above the fold once (so reader doesn't scroll)
- Repeat at bottom of body for longer emails (newsletter / educational)
- Avoid mid-paragraph CTAs (link-clutter)

## Defaults

- No subject line direction from user → propose 3 subject line variants (curiosity / specific outcome / question) for A/B; surface for pick
- No CTA specified → derive from email type (Promo → "Shop now"; Newsletter → "Read the full piece"; Cart → "Complete order")
- No emoji guidance → default to B2C/B2B inference (consumer brand → 1 emoji; professional → none)
- No length guidance → default to promotional 50-150 words; newsletter 150-300 words

## Hard Limits

- Subject line ≤ 50 chars — truncated subjects lose open rate
- Subject line never all caps — spam filter trigger
- Never multiple exclamation marks — spam trigger
- Never fake urgency ("Last chance!" when not true) — erodes deliverability via Gmail tab placement + erodes trust
- One primary CTA — multi-CTA emails drop CTR 70%+
- Mobile-first — 70%+ of emails read on phone; do not optimize for desktop
- CTA button ≥44×44px — mobile tap target standard
- zh-HK / zh-CN markets: respective character set; subject line char limits still apply but Chinese chars carry more meaning per char
- Promo emails for compliance-sensitive categories (medical / health / financial / weight-loss claims) → route through compliance sub-agent
