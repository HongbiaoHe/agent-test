# 示例：一个视频工作流技能的正文

下面是 `save_skill` 的 `instructions` 参数的一个完整示例（不含 frontmatter）。写新技能时照这个结构来，内容换成用户的任务。

---

# 产品预告短片

把一个产品做成 3 个镜头、约 15 秒的预告短片：开场氛围 → 产品特写 → 使用场景收尾。

## 输入

- 产品名与一句话卖点（必需；缺了用 ask_user 问）
- 视觉风格（可选，默认：电影感、暖色侧逆光、浅景深）
- 产品外观描述（可选；没有就根据产品名合理设定，并在三个镜头里保持一致）

## 步骤

1. `write_todos` 列出：设计三个镜头 → 建关键帧节点 → 建视频节点并连线 → 生成关键帧 → 生成视频 → 拼接成片。
2. 设计三个镜头，每镜一句画面 + 一句动作：
   - 镜头 1 开场氛围（5 秒）：产品所在环境的空镜，慢推。
   - 镜头 2 产品特写（5 秒）：产品微距，环绕运镜，突出卖点相关的细节。
   - 镜头 3 使用场景（5 秒）：人物使用产品的瞬间，拉远收尾。
3. 每个镜头 `add_node(image_gen)` 写关键帧提示词，三个节点纵向排开。
4. 每个镜头 `add_node(video_gen)` 放在对应关键帧右侧，写视频提示词，并 `connect_nodes(关键帧 → 视频)`。
5. 在最右侧 `add_node(video_concat)`，按镜头 1、2、3 的顺序把三个 video_gen 连进来（连线顺序就是拼接顺序）。
6. 触发三个关键帧的 `generate_media_node`。视频节点的参考图只取**已完成**的关键帧，所以此时先别触发视频：告诉用户「关键帧生成完后说一声继续」，结束本轮。
7. 下一轮：画布状态里三个关键帧都是 `<生成:done>` 后，依次触发三个视频节点；还有没完成的就只触发已就绪的那几个。
8. 三段视频都 `done` 后 `merge_video_node` 拼接，向用户交付并说明可以在节点面板调整比例/时长后重新生成。

## 提示词写法

- 关键帧：`[产品外观描述]，[场景]，[构图：如三分法/居中特写]，[光线]，[风格]，高细节，无文字`
- 视频：`延续参考图的主体与构图，[主体动作]，[运镜：缓慢推近/环绕/拉远]，[节奏]，约 5 秒，[风格]，无字幕`
- 一致性：产品外观描述在三个镜头里**逐字复用**；风格词三镜统一。

## 检查清单

- 三个 video_gen 都有来自对应关键帧的入边，且触发时对应关键帧已是 `done`。
- video_concat 的入边顺序 = 叙事顺序。
- 提示词里没有要求画面出现文字（生成模型写字不稳定）。
- 需要竖屏等特定比例时，已提醒用户在节点面板设置。
