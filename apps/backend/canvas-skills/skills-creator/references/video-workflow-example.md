# 示例：一个视频工作流技能的正文

下面是 `save_skill` 的 `instructions` 参数的一个完整示例（不含 frontmatter）。写新技能时照这个结构来，内容换成用户的任务。

---

# 产品预告短片

把一个产品做成 3 个镜头、约 15 秒的预告短片：开场氛围 → 产品特写 → 使用场景收尾，最后再续一段产品定格。

## 输入

- 产品名与一句话卖点（必需；缺了用 ask_user 问）
- 视觉风格（可选，默认：电影感、暖色侧逆光、浅景深）
- 画幅（可选，默认 16:9；用户说竖屏 / 抖音就用 9:16）
- 产品图（可选；用户在对话里发了产品图，就用 image_upload 节点挂上它的 versionId，作为产品设定的参考）

## 步骤

1. `write_todos` 列出：确定规格 → 设计镜头 → 搭节点并连线 → 一次触发全部 → 交付。
2. 确定规格：用 `list_media_models` 查一次目录。生图选支持参考图的模型；生视频选支持所需画幅、5 秒时长的模型，镜头 4 要续写，还要支持视频参考。每镜 5 秒。
3. 设计镜头，每镜一句画面 + 一句动作：
   - 镜头 1 开场氛围：产品所在环境的空镜，慢推。
   - 镜头 2 产品特写：产品微距，环绕运镜，突出卖点相关的细节。
   - 镜头 3 使用场景：人物使用产品的瞬间，拉远收尾。
   - 镜头 4 产品定格：延续镜头 3 的结尾，镜头缓缓推回产品并定格。
4. 搭节点（建生成节点时用 `model` / `params` 一并定好画幅与时长，四个视频节点规格一致）：
   - 一个 `image_gen`「产品设定」：写产品外观描述；有产品图时从 image_upload 连进来作参考。
   - 三个 `image_gen` 关键帧（镜头 1–3），各自从「产品设定」连一条线作参考，纵向排开。
   - 三个 `video_gen`（镜头 1–3）放在对应关键帧右侧，各连自己的关键帧。
   - 一个 `video_gen`「镜头 4」放在镜头 3 视频右侧，以镜头 3 的视频为参考。
   - 最右侧一个 `video_concat`，按镜头 1、2、3、4 的顺序把四个视频连进来（连线顺序就是拼接顺序）。
5. 结构全部搭好后，在**同一步里**一次触发全部：产品设定、三个关键帧、四个视频的 `generate_media_node`，以及拼接的 `merge_video_node`。下游会自动等上游出结果，不用分轮、不用等用户说继续。
6. 交付：告诉用户各节点正在按依赖依次生成，完成后成片在最右侧的拼接节点；画幅、时长可以在节点面板里改后重新生成。

## 提示词写法

- 产品设定：`[产品外观描述]，纯色背景，正面 3/4 视角，柔和棚拍光，高细节，无文字`
- 关键帧：`以参考图中的产品为主体，[场景]，[构图：如三分法/居中特写]，[光线]，[风格]，高细节，无文字`
- 视频：`延续参考图的主体与构图，[主体动作]，[运镜：缓慢推近/环绕/拉远]，[节奏]，约 5 秒，[风格]，无字幕`
- 续写：`延续参考视频结尾的画面与运动方向，[接下来的动作]，镜头缓缓推回产品并定格，约 5 秒，[风格]`
- 一致性：产品外观描述在各节点里**逐字复用**；风格词全片统一。

## 检查清单

- 每个镜头视频都有来自对应关键帧的入边；三个关键帧都以「产品设定」为参考；镜头 4 以镜头 3 的视频为参考。
- 所有生成节点的画幅、清晰度一致，视频时长都是 5 秒；所选模型支持对应的参考类型（镜头 4 要能收视频）。
- video_concat 的入边顺序 = 叙事顺序。
- 全部节点在同一步里触发，没有遗漏（漏掉的上游会让下游报错）。
- 提示词里没有要求画面出现文字（生成模型写字不稳定）。
