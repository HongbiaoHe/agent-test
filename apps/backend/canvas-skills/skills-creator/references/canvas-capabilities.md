# 画布智能体能力清单（写技能前必读）

写进技能的每一步都必须落在下面这些能力之内。

## 节点类型

| 类型 | 作用 | 输入（入边） | 输出 |
| --- | --- | --- | --- |
| `image_gen` | 生图。提示词写在节点自己的 `prompt` 上 | 上游图片作参考图（可多张，按连线顺序编号为 Image 1/2…） | 图片 |
| `video_gen` | 生视频。提示词写在节点自己的 `prompt` 上 | 上游图片作参考图；上游视频只用于串联画布，**不参与生成** | 视频 |
| `video_concat` | 把多段上游视频按**入边顺序**拼成一条（本地拼接，不调模型） | 只接视频，至少 2 段且都已生成完 | 视频 |
| `image_upload` | 用户上传图片的占位 | 无输入端口 | 图片（当前为模拟上传，**不能**作为生成的参考图） |

连线 A → B 表示 A 是 B 的上游输入，只传递**参考图/视频素材**；提示词不走连线。

## 工具

| 工具 | 用途 | 要点 |
| --- | --- | --- |
| `write_todos` | 把任务拆成有序计划并逐项推进 | 一次运行内做完全部步骤 |
| `add_node(type, label?, prompt?, x?, y?)` | 新建节点 | 位置放进「放置安全区」；生成节点建时就可以带 prompt |
| `update_node(nodeId, label?, prompt?, x?, y?)` | 改标题 / 提示词 / 位置 | **不能**改节点的模型与档位（比例、分辨率、时长） |
| `connect_nodes(sourceId, targetId)` | 连线 | 遵守上表的输入/输出类型 |
| `delete_node(nodeId)` | 删除单个节点 | 搭错优先 update_node 修，不要删了重建 |
| `clear_canvas()` | 清空整块画布 | 会请用户确认 |
| `generate_media_node(nodeId)` | 触发 image_gen / video_gen 生成（异步） | 先写好 prompt；会请用户确认（审批模式）；触发后不要轮询或重复触发 |
| `merge_video_node(nodeId)` | 触发 video_concat 拼接（异步） | 上游视频都生成完才能拼 |
| `ask_user(question, options?)` | 向用户提问并等待回答 | 只问关键选择 |
| `read_file(path)` | 读文件 | 读技能：`/skills/<名>/SKILL.md` |
| `save_skill(name, description, instructions)` | 保存/覆盖用户技能 | 只在创建或修改技能时用 |

画布当前状态（全部节点、连线、节点 id、放置安全区）会自动出现在对话里，不需要工具去查。

## 限制（技能里不能承诺的事）

- 不能选择或修改生成模型、比例、分辨率、时长、音频开关——这些由用户在节点面板里设置；没设置时用默认模型。技能里需要特定规格时，写成「在提示词里描述构图/节奏」并「提醒用户在节点面板里设置」。
- 生成是异步的，结果不会在同一步里返回。**参考图只取触发那一刻上游已经生成完成的结果**：上游还在排队/生成中就触发下游，下游会在没有参考图的情况下生成。画布状态里每个节点会标出 `<生成:queued|generating|done|failed>`，下游要等上游显示 `done` 再触发；上游没完成时，先把能并行的都触发掉，告诉用户「关键帧生成完后说一声继续」，下一轮再触发下游。
- 不能上传或读取用户本地文件，不能联网搜索，不能运行代码。
- 视频之间的转场、配乐、字幕不在能力之内；只能通过提示词影响画面内容，用 video_concat 顺序拼接。

## 常见视频工作流骨架

1. 关键帧：每个镜头一个 `image_gen`，写好画面提示词（主体 + 场景 + 构图 + 光线 + 风格）。
2. 动起来：每个镜头一个 `video_gen`，从对应关键帧连一条线作参考图，提示词写动作、运镜、节奏与时长感。
3. 成片：一个 `video_concat`，把各镜头的 `video_gen` 按叙事顺序依次连进来，全部生成完后 `merge_video_node`。
   生成顺序：先触发全部关键帧 → 关键帧 `done` 后再触发视频 → 视频全部 `done` 后再拼接（通常要跨几轮对话，每轮结束时告诉用户下一步）。
4. 布局：同一镜头的 image_gen → video_gen 横向排开，镜头之间纵向错开，最右侧放 video_concat。
